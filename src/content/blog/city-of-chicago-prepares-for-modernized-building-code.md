It seems like a life time ago that Phase two of the Modernization of the Chicago Building Code was approved. Now, the city is in its last week of operating under the pre-2019 Chicago Building Code and fully transitioning into the Modernized one. Preparing for what's ahead can be nerve racking but with the right resources and collaborative efforts, the new code will have Chicago frontwards. 

### Focusing on What's Ahead - Chicago Department of Buildings(DOB) Deadlines

-   The last day to *start* permit applications under the pre-2019 Chicago Building Code (CBC) is Friday, July 31. Deposits and fees must be paid by midnight. 
    -   Exceptions to the deadline include: 
        -   Phased projects - If previous phases of a project were issued under the pre-2019 CBC, continued phases can be submitted as such. 
        -   Revisions to existing permits - If an existing permit requires revision and was issued under the pre-2019 CBC it does not need to be adjusted to the modernized code. 
-   Alternative Plumbing Materials Pilot Program has been extended to December 21. 
    -   The program applies to new construction of residential buildings up to 4 stories in height and existing residential and non-residential buildings up to 4 stories in height.
    -   For more information on the pilot program visit the DOB's [Alternative Code Approval webpage](https://www.chicago.gov/city/en/depts/bldgs/supp_info/Alt-code-approval.html).

Is Chicago still operating under the 2019 Chicago Building Code described in this post? This is the same edition's foundational structure, but it's been continually supplemented since. Chicago has issued ongoing supplements to the 2019 code, and the Department of Buildings is currently in a multi-phase initiative to further align city construction requirements more closely with national model codes like the IBC, so while "2019 CBC" is still the base reference, it's not static. Are pre-2019 Chicago Building Code permits still being processed today? No, the deadline described in this post (July 31, with limited exceptions for phased projects and permit revisions) closed that window years ago. Any new permit application today must comply with the current Chicago Building Code, not the legacy pre-2019 code. Is the Alternative Plumbing Materials Pilot Program mentioned in this post still active? That specific 2019-era pilot's original extension (through December 21 of that year) has long since passed - check DOB's current Alternative Code Approval page directly for whatever alternative materials programs are active today, since pilot programs like this are typically time-limited and may have been formalized, replaced, or discontinued since. Where can I get an up-to-date copy of the current Chicago Building Code? The city continues to provide a free, read-only version of the Chicago Construction Codes and supplements through DOB's website, and ICC sells official paper copies of the Illinois/Chicago code editions - though make sure you're pulling the most current supplement rather than the original 2019 base text referenced in this older post. How often does Chicago update or supplement its building code? Chicago doesn't operate on a fixed, predictable cycle the way some jurisdictions tie directly to each new triennial ICC edition - instead, the city issues periodic supplements and has undertaken larger phased modernization efforts (like the one referenced in this post, and the current multi-phase initiative to align with national model codes) as standalone projects.
